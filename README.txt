SERIESHUB — TV SERIES DISCOVERY WEBSITE
============================================

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Double-click index.html.
3. The website runs in a browser.

Features:
- Cinematic responsive UI
- Trending and top-rated sections
- IMDb-style ratings and vote counts
- Search and sorting
- Genre filters
- Favorites saved in browser localStorage
- Random "Surprise Me"
- Series details modal
- Mobile responsive layout

Note:
Poster images in this demo are remote image URLs. Replace the poster URLs in script.js with your own licensed images if you plan to publish the site commercially.
